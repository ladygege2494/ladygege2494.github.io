这里收录我每个学期初给自己制定的学期规划，主要是课业规划，包含一下几个部分：
- 前言：学期目标和重点项目，包括绩点、竞赛、科研。
- 前人经验：开学初高强度爬取本学期所有课程的各路资源（98/问学长/网络），包括课程体验、参考资料、历年卷。
- 我的策略：在第一周，记录本学期所有课程的具体的教学安排和成绩构成，以及会不会点名、卷不卷发言、有几次小测、核心考点等等，以免遗忘疏漏；在前几周，根据自己的课程体验和学习目标，并结合前人经验，有针对性地制定自己的学习策略（听课or自学?课上干嘛课后干嘛？花多少时间？平时好好学or考试周补天？）。前者可以作为选课参考。后者发布时被我删除了，大家可以制定自己的策略。
- 考试周复习规划：包括精确到日的复习规划、历年卷。考虑到每学期的考试时间不同参考意义不大，这部分我也删除了。方法可以借鉴。

本合集旨在让微电子专业的学弟学妹对整个学期的课业侧重点和压力大小有一个宏观的概览和评估，并据此制定属于自己的学习策略。不同于其他章节中较为个人向存在大量主观表述的经验帖，本合集是纯粹公开资源的整合，非常干，量大管饱，但未经筛选。
由于培养方案会变，请读者注意本合集的时效性。
