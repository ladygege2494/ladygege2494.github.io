# 影视地位
曾被誉为最佳亚洲电影
2000年的戛纳被华语电影占据了半壁江山，同时出现了两部我在这里可以爆言几乎公认的华语电影最高峰，王家卫的花样年华和杨德昌的一一。
在2022年英国视与听杂志全球1639位专业影评人评选的影史最佳250榜单中，花样年华排名第五，在全球480位导演评选的影史最佳100榜单中排名第十。在花样年华前面有东京物语、公民凯恩、迷魂记让、纳迪尔曼，而库布里克的2001太空漫游、大卫林奇的穆赫兰道、科波拉的教父都在花样年华之后。
花样年华最初的片名三个关于食物的故事，说的是上个世纪三年发明彻底改变了男女关系。第一样是60年代的电饭煲，他把当时一部分的女性从厨房里面解放了出来，走向社会。第二样是方便面，一个人一碗面是享受单身的开始还是结束？第三样是24小时便利店，它的出现让所有的人在任何时候都可以找到一席之地。
# 视听语言
-----------能指极其发达，所指极其暧昧
用一句话就能讲完的故事
⭐好的导演是会为自己的片子找到最合适的视听语言
- 梅林茂配乐：这段音乐中总有一种列车形式的节奏感。一男一女在片中屡次的错身而过，最近时候的距离只有0.01公分，最终就如这段音乐所表达的那样，一男一女的生命轨迹像两列相向而驰的列车，刹那交集，然后永远的擦身而过。
（不是专为花样年华写的，是他为日本影片梦二定制的音乐。）
- 专门搭有一定纵深度的狭窄的通道：挤压着人与人之间的生活空间，那个年代基本上没有什么隐私可言，表现出人们内心的压抑与束缚
- 家具放错屋子，放错人
- 旗袍：表达特定时代的文化对人性的束缚；时间跳跃
- 王家卫的特点是不希望他的两位主人公被烟火气浸染的，他要他们始终是有腔调的，像两株遗世独存的白莲孤傲绽放，于是把烟火气坐在这些次要人物的身上

本片的视听语言有一以贯之的方案，摄影与构图上的设计总谱呈现出强大的系统感、规划感，这种格律使片子散发出电影感。
## 能指型王家卫，所指型李安
与色戒中麻将戏的对比
⭐对能指与所指的理解是打开所有现代艺术审美的一把金钥匙
绝大部分观众的固定思维都是所指性的，王家卫选的是第1万01种拍法。
他更在意的是视听语言，各元素间怎么调配，而不是它们组合到一起，具体指向了什么意思，或者说你看出什么都可以，对应到你自己的知识结构，你的文化素养。
强戏剧性：活着，霸王别姬，色戒
这种戏剧性不强的电影，恰恰更具有代表性的展现了电影这种艺术本身的独特魅力。
# 故事构想
-----------吸小说家的灵韵，享受自己的春梦
对倒
王家卫请他们并不是要他们的故事人物情节，他要的始终都是小说家用文字为他搭建起的那个场域，是他曾经生活过、迷恋过或者总是他幻想的一个时代。他吸取的不是内容，而是神韵。
”生锈的感情，又逢落雨天。“《酒徒》第一句话
50年前的独上阁楼，最好是夜里。
就像张艺谋始终被同一张脸所吸引，王家卫始终是被同一类文字所折服
枕着浓浓的烟火气，享受他自己的春梦了无痕。
违背大众审美，曾经的票房毒药成了公认的艺术大师，独一无二不可复制
# 审美格调
------------流光容易把人抛，关于时间的咏叹
物哀之美，时间单向度行走，时间的灰烬
“那个时代已经过去，属于那个时代的一切都不复存在了。”
不足：表达所指的局限性，没有中国美学最博大精深的超越哲学。
西方人到了一战后的存在主义哲学，制定了一套向死而生的人生态度；而中国哲学的精髓，讲的是要去撕开时间的皮肤，绕到时间的背后去找到灵魂安顿的方式，从人的有限性中超脱出来。西方哲学重视寻找活着的价值，而中国人更在意超脱活着的痛苦。这是两套根本上不同的哲学观。正所谓诸人背12时辰时，老僧使得12时辰。这里头的东方况味，就是王家卫电影差的那最后一口气
